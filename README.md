# 🌿 Lomas de San Marcos de la Aguada - Guía Completa

Bienvenido a la guía interactiva de las Lomas de San Marcos de la Aguada en el Valle de Mala, Cañete.

## 📄 Páginas disponibles:

### 1. **Guía Principal** ✅
- 📍 Croquis interactivo de caminos
- 🐾 Fauna registrada
- 🥾 Puntos de ruta
- 💚 Sistema de donaciones (Yape y BCP)

**Acceso:** https://santistebanandree-a11y.github.io/lomas-san-marcos/

### 2. **Weather Dashboard** ⚠️ EN DESARROLLO
- 🌡️ Clima actual
- 📅 Pronóstico de 5 días
- 📍 Geolocalización automática
- 🔍 Búsqueda de ciudades

**Nota:** Requiere API Key válida de OpenWeatherMap.

---

## 🚀 Cómo usar:

1. Haz clic en los enlaces arriba para acceder a cada sección
2. En la guía principal, usa los botones para:
   - Abrir ubicaciones en Google Maps
   - Copiar números para donaciones
   - Ver fauna local
